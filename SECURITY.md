# Security Policy

## Supported versions

OpenMaintainer is pre-1.0. Security fixes target the default branch until the first stable release.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Email the maintainers or use a private advisory if the repository is hosted on GitHub. Include:

- Affected version or commit
- Reproduction steps
- Expected impact
- Suggested fix, if known

## Data handling

OpenMaintainer should not receive private repository data unless the maintainer intentionally configures it for a trusted deployment. The default MVP uses public GitHub data and local environment variables for credentials.
