# Roadmap

## Phase 0: Credible MVP

- Public repository inspection
- Demo mode without credentials
- Deterministic issue triage
- Optional OpenAI analysis
- PR review summaries
- Release draft generation
- Similar issue detection
- Copyable maintainer action plan
- Real repository quality signals
- GitHub CLI handoff commands
- Repository playbooks for daily, weekly, and release cadence
- Weekly maintainer digest
- OSS readiness scoring
- CI validation
- OSS documentation and contribution flow

## Phase 1: Maintainer Workflow Depth

- GitHub App authentication
- Label suggestions that can be applied after maintainer approval
- Duplicate issue detection
- Stale issue review
- Release note export
- Duplicate issue workflow actions
- Per-repository settings

## Phase 2: Team Maintenance

- Maintainer assignment suggestions
- Review load balancing
- Contributor onboarding queue
- Multi-language response drafts
- Audit history for AI suggestions

## Phase 3: Open Maintainer Network

- Shared playbooks for OSS projects
- Plugin API for custom maintainer checks
- Security review workflows
- Public benchmark dataset for maintainer-assistant quality
